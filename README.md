# auxiliary-function

Code for computing symmetry-allowed crystal-field eigenstate structures and auxiliary densities for f-electron systems (NdCl3, YbBr3, CeN)

For rows with a "Run this first" script: run it once to generate the required `.mat` data file, then run the corresponding plot script.

## Crystal-field parameters

Crystal-field parameters used in these scripts were obtained from McPhase 5.2 (run separately) and entered manually into the MATLAB code; they are not computed within these scripts.
